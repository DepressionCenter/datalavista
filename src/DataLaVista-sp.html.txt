How to use this file:
1. Upload datalavista.js from the dist folder to your site's Site Assets library

2. On your site's home page, select New, then Page, and choose the Modern Script Editor
   template. Name the page DataLaVista, so its address ends in /SitePages/DataLaVista.aspx.
3. In the Modern Script Editor web part, select the "{ }" button under Edit HTML Code.
4. Paste the entire contents of this file into the code editor. Select Save in the code
   editor, then select Save on the page.
5. Refresh the page.
