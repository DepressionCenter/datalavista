# DataLaVista™

## Preview a dashboard

[Back to help home](../README.md)

This page explains what to look for on the Preview Dashboard tab, which shows
the dashboard the way people who receive a link will see it. It is for anyone
about to share a dashboard. Preview every dashboard before you publish it.

### The preview

The Preview Dashboard tab hides the designer and renders the dashboard on its
own. Use it to check that:

- each filter changes every widget it should,
- the numbers and chart values match what you saw in the results preview on the
  Query tab,
- hover text and clicks behave the way you expect,
- the layout holds up at the screen sizes your readers use.

Compare a few key numbers with a source you trust, such as a SharePoint list
view or an Excel export. A few minutes here save a correction after the
dashboard is shared.

### Download the data behind the dashboard

From the preview you can download the data the dashboard uses as a CSV file.
This is the quickest way to confirm what a chart is plotting, to send a small
extract for review, or to answer the question of where a number came from.

### Conclusion

You can now confirm that filters, numbers, and layout are right before anyone
else sees them. Next, save and share the dashboard in
[Publish and share a dashboard](publish-and-share.md).
