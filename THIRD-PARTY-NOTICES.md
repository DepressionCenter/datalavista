# DataLaVista™

## Third-party notices

[Back to project README](README.md)

DataLaVista is licensed under the GNU General Public License version 3 or later.
See [LICENSE](LICENSE). The built files in `dist/` also contain copies of the
libraries below, packed from `src/lib`. Each library keeps its own license, and
its full text follows. These licenses apply only to the library files named
here, not to the rest of DataLaVista. This page is for anyone who redistributes
the built files or reviews what they contain.

### Libraries packed into the built files

| Library | Files in `src/lib` | Source | License | Used for |
| --- | --- | --- | --- | --- |
| AlaSQL 4.17.2 | `alasql.min.js` | [alasql on npm](https://www.npmjs.com/package/alasql) | MIT License | Runs the SQL queries in the browser. |
| Apache ECharts 6.0.0 | `echarts.min.js` | [echarts on npm](https://www.npmjs.com/package/echarts) | Apache License 2.0 | Draws the charts. |
| Apache ECharts custom violin series 1.1.1 | `echarts-custom-violin.auto.js` | [@echarts-x/custom-violin on npm](https://www.npmjs.com/package/@echarts-x/custom-violin) | Apache License 2.0 | Adds the violin plot chart type. |
| SheetJS Community Edition 0.20.3 | `xlsx.full.min.js` | [cdn.sheetjs.com](https://cdn.sheetjs.com/) | Apache License 2.0 | Reads Excel files. |
| CodeMirror 5.65.16 | `codemirror.min.js`, `codemirror-sql.min.js`, `codemirror-show-hint.min.js`, `codemirror-sql-hint.min.js`, `codemirror.min.css`, `codemirror-show-hint.min.css` | [codemirror on cdnjs](https://cdnjs.com/libraries/codemirror/5.65.16) | MIT License | The SQL editor with highlighting and name completion. |
| lz-string 1.5.0 | `lz-string.min.js` | [lz-string on cdnjs](https://cdnjs.com/libraries/lz-string/1.5.0) | MIT License | Compresses uploaded data inside a saved dashboard file. |
| sql.js 1.8.0 | `sql-wasm.js`, `sql-wasm.wasm` | [sql.js on cdnjs](https://cdnjs.com/libraries/sql.js/1.8.0) | MIT License | Reads SQLite database files. SQLite itself is in the public domain. |

The build checks every file against `src/lib/sha256sums.txt` before packing it,
and refuses to run when a file does not match. The same license texts are in
`src/lib`, in the file named in each section below.

To update a library, download the new release from its source above into
`src/lib`, replace its line in `src/lib/sha256sums.txt` with the new checksum,
update its version in the table above and in `docs/compliance.md`, and copy any
changed license text into this page.
